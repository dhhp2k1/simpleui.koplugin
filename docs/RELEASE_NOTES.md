基于原版 SimpleUI 3.0.1 的个人版本，已同步至上游 main `71ed399`（2026-10-29）。适配目标为 Paperwhite 5、固件 5.16.2.1.1、KOReader 2026.03+。

本版更新：

- Kindle 实机修复：书库页码在首页重建、隐藏和恢复后保留；末页书籍减少时退到最后一个有效页；恢复隐藏的书不再被当作新书，并立即提示书名；通过 LocalSend 等方式收到新书后，首页下次重绘（翻页、切回首页或看书返回）时回到第一页。
- 同步上游 44 个提交：首页残影更少，可选每次翻页闪屏；书库搜索和排序对中文等非拉丁文字不区分大小写；书籍信息缓存损坏时自动恢复；启动更快；首页网格支持堆叠和自由宽度；迷你小伙伴新增小游戏、名言、角色台词和新角色 Hazel；顶栏显示蓝牙状态；快捷操作支持网格布局；启动时检测并可停用与 Simple UI 冲突的用户补丁。
- 简体和繁体中文：补译上游新增的 560 条字符串，覆盖率 2345/2346（仅文字时钟的分隔符按设计留空）；保留个人版既有译法（迷你小伙伴、快捷设置；繁体的行／列、預設檔、暖光）。

个人版功能（沿用）：

- 平铺书库默认按文件日期从新到旧，保留已有排序选择。
- 新书加入后回到第一页，普通翻页、删书和隐藏保持当前分页。
- 可恢复的书籍隐藏功能，原文件、批注和历史保留。
- 个人更新来源和版本后缀识别；未加入 AI 或资讯。

可在 Simple UI 的“关于 → 检查更新”中直接更新；也可下载 simpleui.koplugin.zip 和 SHA256SUMS，退出 KOReader 后将解压的 simpleui.koplugin 放入 koreader/plugins/。

实机修复已在 PW5 上验收；上游合并部分已通过桌面回归和安装包检查，实机复测记录见 docs/DEVICE_VALIDATION.md。安装前请备份现有插件和设置。
