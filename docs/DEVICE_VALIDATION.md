# PW5 实机验证记录

验证设备：Kindle Paperwhite 5，固件 5.16.2.1.1，KOReader 2026.07.1 kindlepw2，
启用自带 CoverBrowser。验证日期：2026-10-26。当前分支修复由两轮设备排查合并而来，
尚未发布新的个人版本；现有 v3.0.0-personal.2 Release 保留原样。

## 已验证

- KOReader 启动、退出、休眠唤醒与再次启动正常。
- SimpleUI 顶底栏、连续打开关闭两本书和阅读进度正常。
- 隐藏后保留书库页码，恢复后显示成功提示，原 EPUB 和批注保持完整。
- 正在阅读卡片与两排书库可同时完整显示。此次采用紧凑卡片和缩小书库封面的个人设置；
  本次代码修复不会强制改变其他用户的首页布局，也不保证任意组件组合都能容纳于同一页。
- 用 LocalSend v2 协议传入 EPUB 后，保活首页在下次重绘时回到第 1 页，新书排在最前。

## 接受的限制

LocalSend 收书不发送 KOReader 的书库更新事件。为避免增加定时检查，本分支只在书库
组件下次构建时检查磁盘清单，例如翻页、切回首页或看书返回。收书瞬间不强制跳页。

文件日期排序使用修改时间；其他排序保留用户选择。隐藏仅改变展示，不删除或移动原书、
批注及历史。外部改名、移动书籍后，隐藏记录仍须手动处理。

## 自动回归范围

`tests/test_device_regressions.py` 使用 LuaJIT 2.1 覆盖：

- 首页上下文重建、隐藏和恢复后的页码，以及不同界面之间的隔离。
- 真正新增文件才重置最新加入排序；标题排序下新书到达继续保留排序和分页。
- 已缓存网格收到新书后的缓存失效与分页更新。
- 末页缩短后选取最后一个有效页。
- 恢复显示的即时反馈。
- 首次向导可构建预设列表并选择预设。

CI 在 Windows、Linux 运行上述用例、既有三组回归和安装包结构检查。桌面桩测试不替代
其他硬件、固件或任意布局的实机验证。
